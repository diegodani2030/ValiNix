Esta carpeta es para las imágenes reales del proyecto (ej. og-cover.jpg para Open Graph,
fotos de proyectos del portafolio, etc.).

Por diseño, la landing page NO depende de imágenes para funcionar: los mockups del hero,
los iconos de servicios y las miniaturas del portafolio están hechos en SVG/CSS puro,
así que el sitio se ve completo aunque esta carpeta esté vacía.

Cuando tengas fotos reales de proyectos, agrégalas aquí y actualiza las clases
".project-card__thumb" en css/style.css (o agrega <img> dentro de ".project-card__thumb")
para mostrarlas.
